# 📋 Product Survey Feedback Form

A clean and simple feedback form with a modal dialog box for user submissions.

## 💻 Technologies

- HTML, CSS, JavaScript
- SVG illustrations

## 🚀 Features

- **Clean Form Design:** Simple and minimal input fields for feedback collection.
- **Thank You Modal:** Displays a modal dialog after form submission instead of inline confirmation.
- **Close Button:** Exit modal with close button (✕) or "Close" button.
- **Purple Accents:** Elegant light purple styling for headings and buttons.
- **SVG Icon:** Simple illustrated icon at the top.

## 🧠 What I Learned

- **Modal Implementation:** Creating overlay dialogs with fixed positioning and active states.
- **Event Handling:** Managing form submission and modal visibility with JavaScript.
- **CSS Styling:** Minimalist design with subtle purple accents and focus states.

**Note:** Form data is displayed in the modal but not persisted or sent to a server.

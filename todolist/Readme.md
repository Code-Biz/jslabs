# 📝 To-Do List App

A simple and interactive to-do list application designed to help you manage tasks efficiently with a clean and modern UI.

## 💻 Technologies

- HTML, JavaScript, and Tailwind CSS v4
- DaisyUI for enhanced UI components

## 🚀 Features

- **Task Management:** Add, mark as complete, and delete tasks seamlessly.
- **Clear All:** Quickly clear all tasks or only completed ones.
- **Responsive Design:** Optimized for both desktop and mobile devices.

## 🧠 What I Learned

- **DOM Manipulation:** Using `document.createElement`, `addEventListener`, 'querySelector`and`innerHTML` to dynamically update the UI.
- **State Management:** Managing task states (completed/incomplete) with JavaScript arrays.
- **Modern CSS Frameworks:** Leveraging Tailwind CSS and DaisyUI for rapid UI development.

## ⚙️ The Process

I started by building the core functionality of the app—adding, toggling, and clearing tasks. Once the logic was in place, I integrated Tailwind CSS and DaisyUI to enhance the design. The focus was on creating a user-friendly and visually appealing interface.

## ⚡ Running the Project

1. **Clone** the repo.
2. **Install Tailwind:** `npm install -D tailwindcss @tailwindcss/cli`
3. **Build CSS:** `npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch`
4. **Launch:** Open `todo_list.html`.
